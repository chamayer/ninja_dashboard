Finding types

Everything configurable for a finding is here: its name, where it sits in the Issues page, its default severity, whether it may alert, and which findings cover it. A covered finding is hidden under its parent while the parent is open on the same computer, and returns by itself when the parent clears and it is still true. Covering never lowers urgency: a parent shows the highest severity of what it covers. Rules a type is subject to are shown for reference; they are behavior and change only through the policy. Changes are recorded in the audit log.{% if not can_edit %} Only staff can make changes.{% endif %}
