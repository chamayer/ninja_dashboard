# Ninja RMM API reference

Place locally obtained Ninja RMM OpenAPI/API JSON exports in this directory:

- `NinjaRMM-API-v2.json`
- `NinjaRMM-API-v2_formatted.json`

They support connector, schema, and endpoint design. They are vendor-generated
development reference artifacts, not application runtime inputs, and are
intentionally ignored because of their size. Refresh them from the approved
Ninja documentation/source when their version is no longer suitable for the
task; do not treat an export as proof of deployed API availability.
