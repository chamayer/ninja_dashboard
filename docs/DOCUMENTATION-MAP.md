# Documentation map

The canonical navigation is `docs/README.md`.

- Root architecture: `docs/architecture.md`
- Root requirements: `docs/requirements.md`
- Root operations: `docs/operations.md`
- Root decisions: `docs/decisions/`
- Development references: `docs/reference/`
- Maintenance records: `docs/records/`
- Operations module documentation: `operations/docs/`
- Active work: root or module `BLUEPRINT.md`
- Deferred work: root or module `TODO.md`
- History: root or module `SESSIONS.md`, read selectively
- Superseded material: `docs/archive/` or `operations/docs/archive/`
