solely by buffer size or cumulative counters.

## Matcher fixes prepared after continuation request

The user explicitly requested continuation through the unresolved Ninja fix.
The existing commit/push authorization continues for that CPU task. Release
0.142.2 contains two bounded changes to the matcher, with no new migration,
dependency, schema change, matching rule, or persistent planner setting.

1. Reuse CPE query results within one full run, capped at 20,000 rows and 256
   pools. Candidate SQL and the product-only 500-row cap are unchanged. Large
   pools are returned in full but not retained when over the cache budget.
2. Query CVEs in batches of at most 500 CPE keys and deduplicate the union.
   Any-key semantics, version separation, the full rebuild, and stale-match
   withdrawal remain enforced by the existing matcher and regression tests.

Read-only aggregate catalogue measurement: 25,130 titles generated 13,005
candidate requests and 2,410 distinct pools. Simulated reuse with both bounds
was 6,347 requests, with peak 20,000 retained rows. This is an estimate in
catalogue order, not an installed-title matcher-run speedup.

Two live repeated-pool checks each returned identical 500-row results. Ten
queries became one; elapsed time was 0.214866→0.034068 s and
0.158948→0.013970 s. Actual cache code was copied as a reviewed read-only
diagnostic, not installed over runtime code; temporary files were removed.

CVE EXPLAIN plans used the GIN index at 500 and 2,048 candidates but switched
to a sequential scan at 8,192. A real matcher CVE lookup was observed active
for more than three minutes. In a separate bounded repeatable-read comparison,
the original 8,192-key query was cancelled at 3.059 seconds. The 17-batch lookup
completed in 0.507540 seconds and returned exactly the same eight CVEs as the
original query forced through its existing index in that diagnostic session.
No persistent planner configuration or live data was changed by the probes.

The software aggregation plan estimated 600,485 input rows, cost 268,913.52,
and 121 JIT functions. A per-CPE-key join alternative produced worse estimated
plans and was rejected. No speculative software aggregation rewrite is included.
